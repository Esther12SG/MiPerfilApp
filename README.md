# MiPerfilApp

Este proyecto es una aplicación móvil desarrollada en Android Studio con Kotlin.

La aplicación permite registrar un usuario, iniciar sesión con sus datos y luego ingresar a una pantalla de perfil donde se muestra su nombre y correo.

También agregué la opción de tomar una fotografía directamente con la cámara del celular o elegir una imagen desde la galería para mostrarla como foto de perfil.

## ¿Qué hace la aplicación?

Entre las funciones principales se encuentran:

- Registro de nuevos usuarios.
- Inicio de sesión con correo y contraseña.
- Validación de datos antes de ingresar.
- Almacenamiento de usuarios con SQLite.
- Pantalla de perfil con nombre y correo.
- Opción para tomar una fotografía.
- Opción para elegir una imagen desde la galería.
- Cierre de sesión.

## Herramientas utilizadas

Para desarrollar la aplicación trabajé con:

- Android Studio
- Kotlin
- XML
- SQLite

## Sobre los datos

Los datos del usuario se guardan de forma local utilizando SQLite.

La información que se almacena es:

- Nombre
- Correo
- Contraseña

La fotografía de perfil no se guarda dentro de la base de datos, únicamente se muestra mientras se utiliza la aplicación.

## Pruebas

La aplicación fue probada directamente en un dispositivo Android para comprobar el funcionamiento del registro, inicio de sesión, cámara, galería y perfil.
